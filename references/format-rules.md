# 格式与体例层规则（阶段①确定性检查产出，供核对与排查）

以下问题由脚本判定，置信度为「确定」，唯一的例外是 P0「主体串写」。本文件记录判定标准，供人工复核与规则调整时参考。
语义层不要重复报告这些类别（见 content-rules.md）。

## 字体一致性
中文字体、西文字体、字号与全文主流值不一致。主流值定义为出现次数最多的取值，且其占比不低于 60%，否则不报；参与统计的段落少于 3 个也不报。偏离段落逐条列出文件名、段序、实际值与主流值。段落样式取该段落首个非空 run 的属性；段落没有非空 run 时记为「未设置」，不继承段落样式。

## 段落格式一致性
对齐方式、左缩进、首行缩进、行距、段前距、段后距与主流值不一致。判定规则同字体一致性。

## 标题层级体例
同一层级内混用两种以上标题编号写法即报。体系清单：第一章式、一、式、1. 式、（一）式、1.1 式。
不同层级用不同写法是正常结构（第一章 / 一、 / 1. /（一）），不因此报体例不一致。
另检查标题层级跳级：上一级标题与本标题之间缺少中间层级（如 H1 直接跳 H3）即报。

## 图表题注体例
同一文件内出现两种以上题注写法即报。写法清单：图N-N、图N.N、图N、表N-N、表N.N、表N。
另检查图表编号缺号：同一章内编号不连续即报。

## 表格体例
各表首行的加粗写法与全文主流写法不一致即报，主流写法占比不低于 60% 才报。
xlsx 的表头行取首行非空且下方存在数据的行。

## 主体名称
同一主体出现两种以上名称写法。变体判定基于核心字号：名称去掉公司词尾与行政区划前缀后的剩余部分；核心字号相同，或两者互为后缀，或较短者是较长者的前缀且为简称形态（不超过 3 字，或以行政区划开头），视为同一主体。行业词不剥离，「华信科技」与「华信信息技术」是两个不同主体。

## 主体串写
同一文件内出现两个及以上不同主体名称即报。因无外部依据，置信度为「疑似 · 需人工核实」，不升级为确定。文件名或章节标题中已出现这些主体名、说明它们被显式区分时，不报。

## 数字与单位
同一文件内货币单位（元、万元）混用报 P1。日期格式（2024年1月1日、2024-01-01、2024/01/01、2024.01.01）混用报 P2。

## 引用标记
同一文件内引用标记写法（文献[n]、[n]、（n））混用即报。编号越界与参考文献表缺项由智能体在语义层核对。

## 列表与编号
有序列表编号方式混用即报。

## 术语与缩写
缩写首次出现时未给出全称即报（PDF、ISO 等通用缩写除外）。脚本会给出候选缩写，语义层只需核对结论是否成立，不要另写一条同义条目。

## 置信度标注
pdf 抽取的样式数据置信度为低，不参与一致性统计，相关结论不产出。md 与 txt 无样式概念，格式类检查项标为「不适用」。
